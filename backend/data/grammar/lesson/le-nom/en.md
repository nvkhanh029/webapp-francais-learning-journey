# Nouns

## Introduction

A noun (`nom`) designates an animate being (people or animals) or an inanimate thing (an object, an idea, a feeling, an event, etc.). It generally varies according to **gender** and **number**.

There are two groups of nouns:

- **Common nouns (`noms communs`)**: they designate people or things.
- **Proper nouns (`noms propres`)**: they designate unique people or things and begin with a capital letter.

Common nouns can belong to several categories:

- **animate**: homme
- **inanimate**: table
- **countable**: arbre
- **uncountable**: eau
- **abstract**: courage
- **concrete**: livre

A noun can belong to several categories at the same time. For example, `arbre` is inanimate, countable, and concrete.

Examples of proper nouns:

- monsieur Dubois
- Émile Zola
- le Louvre
- les Alpes

# I. Les noms animés : formation du féminin

## 1. General rule

The feminine form is generally formed by adding **-e** to the written masculine form.

Examples:

- un employé → une employée
- un étudiant → une étudiante

However, many nouns already end in **-e** in the masculine form. The determiner then indicates the gender.

Examples:

- un / une élève
- un / une stagiaire
- un / une artiste
- mon / ma camarade

The word `enfant` has one form for both genders:

- un / une enfant

## 2. Orthographic and phonetic modifications

There are two main cases.

### The addition of -e does not change the pronunciation

Examples:

- un ami → une amie
- un employé → une employée
- un inconnu → une inconnue
- un rival → une rivale
- un Espagnol → une Espagnole

For nationality names, remember to use a capital letter:

- un Chinois

Compare this with the adjective:

- la cuisine chinoise

### The pronunciation changes

The final consonant of the masculine form may be pronounced in the feminine form.

Examples:

- un marchand → une marchande
- un candidat → une candidate
- un bourgeois → une bourgeoise
- un Anglais → une Anglaise
- un boulanger → une boulangère
- un infirmier → une infirmière

The addition of **-e** can also cause other phonetic changes.

Examples:

- un Européen → une Européenne
- un champion → une championne
- un cousin → une cousine
- un Mexicain → une Mexicaine
- un Catalan → une Catalane
- un paysan → une paysanne

The final syllable may also change:

- un acheteur → une acheteuse
- un danseur → une danseuse
- un directeur → une directrice
- un fugitif → une fugitive
- un veuf → une veuve
- un maître → une maîtresse

## 3. Nouns with the same root but different endings

Some masculine and feminine nouns have the same root but different endings.

Examples:

- un compagnon → une compagne
- un héros → une héroïne
- un serviteur → une servante
- un jumeau → une jumelle
- un dieu → une déesse

## 4. Professions

Some profession names traditionally did not have a feminine form, but the current tendency is to feminize them.

### Using a feminine determiner

Examples:

- un / une juge
- un / une ministre
- un / une cinéaste

### Adding -e to the written masculine form

Examples:

- un / une auteur(e)
- un / une professeur(e)
- un / une magistrat(e)
- un / une écrivain(e)

### Creating a specific feminine form

Examples:

- un metteur en scène → une metteuse en scène
- un sculpteur → une sculptrice
- un compositeur → une compositrice

## 5. Nouns with only one gender

Some nouns, often animal names, have only one grammatical gender.

Examples:

**Masculine:**

- un animal
- un perroquet
- un écureuil
- un bourreau

**Feminine:**

- une victime
- une souris
- une grenouille
- une panthère

## 6. Nouns whose feminine form is different

Some nouns have a completely different feminine form.

Examples:

- un homme → une femme
- un neveu → une nièce
- un oncle → une tante
- un roi → une reine
- un cheval → une jument
- un mâle → une femelle

# II. Le genre des noms inanimés

## Common nouns

The gender of a common noun is indicated by its determiner.

It is arbitrary, so it must be known or checked in a dictionary.

Examples:

- une table
- la fleur
- un livre
- le bonheur

## 1. Gender and noun endings

Noun endings can indicate gender, but there are many exceptions.

### Common masculine endings

- **-isme** → le journalisme
- **-ment** → le mouvement
- **-age** → le voyage
- **-eau** → le bureau, le noyau
- **-phone** → le téléphone
- **-oir** → le soir
- **-et** → le paquet
- **-al** → le journal
- **-ier** → le pommier

The ending **-age** has exceptions such as:

- une page
- une image
- une plage
- une rage
- une cage
- une nage

### Common feminine endings

- **-té** → la qualité
- **-ion** → la question
- **-eur** → la fleur
- **-ie** → la sociologie
- **-ure** → la fermeture
- **-esse** → la richesse
- **-ette** → la raquette
- **-ence** → l'expérience
- **-ance** → la balance
- **-ée** → l'arrivée
- **-ade** → la salade
- **-ude** → la solitude
- **-ise** → l'entreprise

There are exceptions, for example:

- le bonheur
- le malheur
- le musée
- le lycée

## 2. Colours, languages and infinitives used as nouns

They are masculine.

Examples:

- le vert
- le portugais
- le pouvoir

## 3. Homonyms

Homonyms are words that are written and pronounced in the same way.

Some homonyms change meaning depending on whether they are masculine or feminine.

| Masculine | Feminine |
|---|---|
| un livre de français | une livre de tomates |
| un manche de couteau | une manche de robe |
| le mode subjonctif | la mode des années 1980 |
| le Tour de France | la tour Eiffel |
| le poste de TV | la poste |
| un mémoire de maîtrise | la mémoire |

## Proper nouns

### 1. Countries

Country names ending in **-e** are feminine.

Examples:

- la France
- l'Italie
- la Normandie

Other country names are masculine.

Examples:

- le Japon
- le Canada
- le Languedoc
- l'Afghanistan

### 2. Cities

The gender of city names is not fixed.

When a city name ends in **-e**, it tends to be considered feminine.

Example:

- Toulouse est grande.

Other city names are considered masculine.

Examples:

- Paris est grand et beau.
- Le vieux Paris.

It is also possible to say:

- Paris est une grande ville.

### 3. Mountains, rivers and other geographical names

The gender of these names is arbitrary.

Examples:

- le Jura
- le Caucase
- le Rhône
- le Nil
- le mont Blanc
- la Seine
- la Volga
- les Pyrénées

# III. Le pluriel des noms

## General rule

The plural is generally formed by adding **-s** to the written singular form.

Examples:

- un enfant → des enfants
- une chaise → des chaises

## 1. Nouns ending in -s, -x or -z

These nouns do not change their written form in the plural.

Examples:

- un pays → des pays
- un gaz → des gaz
- une voix → des voix

## 2. Nouns ending in -eau, -au or -eu

These nouns generally take **-x** in the plural.

Examples:

- un bateau → des bateaux
- un tuyau → des tuyaux
- un cheveu → des cheveux

Exceptions:

- un pneu → des pneus
- un bleu → des bleus

## 3. Nouns ending in -ou

Seven nouns ending in **-ou** take **-x** in the plural:

- bijou → bijoux
- caillou → cailloux
- chou → choux
- genou → genoux
- hibou → hiboux
- joujou → joujoux
- pou → poux

Other nouns ending in **-ou** follow the general rule.

## 4. Nouns ending in -ail

About ten nouns ending in **-ail** have a plural in **-aux**.

Examples:

- travail → travaux
- corail → coraux
- émail → émaux
- vitrail → vitraux

Other nouns follow the general rule.

Example:

- un éventail → des éventails

## 5. Nouns ending in -al

About thirty nouns ending in **-al** have a plural in **-aux**.

Examples:

- animal → animaux
- cheval → chevaux
- journal → journaux
- hôpital → hôpitaux

Other nouns follow the general rule.

Examples:

- un bal → des bals
- un festival → des festivals
- un carnaval → des carnavals

## 6. Irregular plurals

Some nouns have irregular plural forms.

Examples:

- œil → yeux
- monsieur → messieurs
- jeune homme → jeunes gens
- madame → mesdames
- ciel → cieux
- mademoiselle → mesdemoiselles

There are also irregular pronunciation patterns.

For example:

- un œuf → des œufs
- un bœuf → des bœufs

## 7. Plural of proper nouns

Proper nouns do not normally take **-s** in the plural.

Example:

- Nous avons invité les Durand à dîner.

However, names of artists can be pluralized when referring to their works.

Example:

- Ils possèdent deux Renoir.

This means:

- deux tableaux de Renoir

## 8. Plural of compound nouns

The plural of compound nouns depends on their formation.

### Verb + noun complement

The verb is invariable and the noun is variable.

Examples:

- un ouvre-boîte → des ouvre-boîtes
- un porte-avions → des porte-avions

But:

- un porte-monnaie → des porte-monnaie
- un chasse-neige → des chasse-neige

### Noun + noun

Both words can be variable.

Examples:

- un chou-fleur → des choux-fleurs
- une porte-fenêtre → des portes-fenêtres

But:

- un timbre-poste → des timbres-poste

### Noun + adjective / adjective + noun / adjective + adjective

Both words are variable.

Examples:

- un coffre-fort → des coffres-forts
- un grand-père → des grands-pères
- une petite-fille → des petites-filles
- un sourd-muet → des sourds-muets

### Irregular pronunciation

The pronunciation of `œuf` and `bœuf` changes in the plural.

- un œuf → des œufs
- un bœuf → des bœufs

The feminine noun `grand-mère` has the following plural:

- une grand-mère → des grands-mères
