# Past participle agreement

## 1. With auxiliary être

The participle agrees with the subject:

- il est allé / elle est allée / ils sont allés / elles sont allées.
- Elle s'est levée. / Ils se sont couchés.

## 2. With auxiliary avoir

By default there is no agreement with the subject:

- Elle a mangé. (no extra `-e`)

Agreement happens only with a direct object (COD) placed **before** the verb:

- La robe que j'ai achetée. (`achetée` agrees with feminine `robe`.)
- Les films que nous avons vus.
- Combien de pommes as-tu mangées ?

## 3. Agreement endings

|  | Singular | Plural |
|---|---|---|
| Masculine | - (allé) | -s (allés) |
| Feminine | -e (allée) | -es (allées) |

## Contrast examples

- Elle est sortie. (She went out.)
- Elle a sorti la poubelle. (She took out the trash — no agreement because the object follows.)
- Ils se sont lavés. (They washed themselves.)
