# Imperfect formation

## Formula

Take the `nous` present form, drop `-ons`, then add: `-ais, -ais, -ait, -ions, -iez, -aient`.

Examples:

- parler: nous parlons -> `parl-` -> je parlais, tu parlais, il parlait, nous parlions, vous parliez, ils parlaient.
- finir: nous finissons -> `finiss-` -> je finissais...
- prendre: nous prenons -> `pren-` -> je prenais...

## The only irregular verb

`être` uses the stem `ét-`: j'étais, tu étais, il était, nous étions, vous étiez, ils étaient.

## Examples

- Quand j'étais petit, je jouais au foot. (When I was little, I used to play football.)
- Il faisait beau. (The weather was nice.)
- Nous habitions à Paris. (We used to live in Paris.)
- Vous lisiez beaucoup ? (Did you read a lot back then?)
- Elles venaient chaque jour. (They came every day.)

## Main uses

Habits in the past, background, description: `chaque jour, souvent, toujours, quand, pendant que`.
