# Irregular future stems

## Principle

Endings stay the same (`-ai, -as, -a, -ons, -ez, -ont`), but the stem is not the infinitive.

## Table of 12 stems to memorize

| Verb | Future stem | Example |
|---|---|---|
| être | ser- | je serai |
| avoir | aur- | j'aurai |
| aller | ir- | j'irai |
| faire | fer- | je ferai |
| pouvoir | pourr- | je pourrai |
| vouloir | voudr- | je voudrai |
| venir | viendr- | je viendrai |
| voir | verr- | je verrai |
| envoyer | enverr- | j'enverrai |
| savoir | saur- | je saurai |
| devoir | devr- | je devrai |
| recevoir | recevr- | je recevrai |

Tip: the `-rr-` group (pourrai, verrai, enverrai) always has a double `r`.

## Examples

- Je serai là. (I will be there.)
- Tu auras le temps. (You will have time.)
- Il faudra étudier. (It will be necessary to study.)
- Nous verrons le film. (We will see the film.)
- Vous recevrez un mail. (You will receive an email.)
