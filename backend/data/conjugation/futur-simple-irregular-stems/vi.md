# Gốc bất quy tắc của futur simple

## Nguyên tắc

Vẫn dùng đuôi `-ai, -as, -a, -ons, -ez, -ont`, nhưng gốc không phải nguyên mẫu.

## Bảng 12 gốc cần nhớ

| Động từ | Gốc tương lai | Ví dụ je |
|---|---|---|
| être | ser- | je serai |
| avoir | aur- | j'aurai |
| aller | ir- | j'irai |
| faire | fer- | je ferai |
| pouvoir | pourr- | je pourrai |
| vouloir | voudr- | je voudrai |
| venir | viendr- | je viendrai |
| voir | verr- | je verrai |
| envoyer | enverr- | j'enverrai |
| savoir | saur- | je saurai |
| devoir | devr- | je devrai |
| recevoir | recevr- | je recevrai |

Mẹo: nhóm `-rr-` (pourrai, verrai, enverrai) luôn có hai chữ `r`.

## Ví dụ

- Je serai là. (Tôi sẽ ở đó.)
- Tu auras le temps. (Bạn sẽ có thời gian.)
- Il faudra étudier. (Sẽ cần phải học.)
- Nous verrons le film. (Chúng ta sẽ xem phim.)
- Vous recevrez un mail. (Các bạn sẽ nhận được email.)
