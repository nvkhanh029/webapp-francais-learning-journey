This page introduces French punctuation marks, the apostrophe for elision, and the basic capitalization rules. Some rules are different from English and Vietnamese.

## Common punctuation marks

| Mark | Name | Example |
| --- | --- | --- |
| **.** | *point* | Je parle français. |
| **,** | *virgule* | Il mange du pain, du fromage et des fruits. |
| **?** | *point d'interrogation* | Tu as faim ? |
| **!** | *point d'exclamation* | Bonne journée ! |
| **:** | *deux-points* | Il y a trois choses : le pain, le fromage et le vin. |
| **;** | *point-virgule* | J'aime le thé ; elle préfère le café. |
| **« »** | *guillemets* | Elle dit : « Bonjour ! » |
| **…** | *points de suspension* | Je ne sais pas… |
| **-** | *trait d'union* | grand-mère, peut-être, Parlez-vous français ? |
| **'** | *apostrophe* | l'ami, j'habite |

## Spaces before punctuation

In French, the two-part marks **? ! : ;** usually have **a space before them**, while the full stop and the comma do not.

| Correct | Not the French convention |
| --- | --- |
| Tu viens ? | Tu viens? |
| Bonjour ! | Bonjour! |
| Il y a deux choses : le pain et le lait. | Il y a deux choses: le pain et le lait. |
| Je parle français. | Je parle français . |

With the quotation marks **« »**, there is a space inside each mark: Elle dit : « Bonjour ! »

> **Tip:** when typing on a phone, many people drop these spaces. That is acceptable in text messages, but formal writing should keep the convention.

## The apostrophe (elision)

Some short words lose their final vowel before a vowel or a silent *h*. The apostrophe takes the place of the lost vowel. This is called **elision** (`élision`).

| Word | Elided form | Example |
| --- | --- | --- |
| je | j' | j'habite, j'aime |
| le, la | l' | l'ami, l'école |
| de | d' | un verre d'eau |
| ne | n' | je n'ai pas |
| me, te, se | m', t', s' | il s'appelle |
| que | qu' | qu'est-ce que c'est ? |
| ce | c' | c'est un livre |

*Si* is elided only before *il* and *ils*: *s'il vous plaît*, but *si elle vient*.

## The hyphen (trait d'union)

The hyphen is used in:

- inverted questions: *Parlez-vous français ?*, *Où vas-tu ?*
- many compound nouns: *grand-père*, *chou-fleur*
- some fixed expressions: *peut-être*, *c'est-à-dire*, *est-ce que* (*Est-ce que tu viens ?*)

## Capital letters

The first letter of a sentence and of a proper name is capitalized: *Marie*, *Paris*, *la France*.

Unlike English, French does **not** capitalize:

| Category | Correct example |
| --- | --- |
| days of the week | lundi, mardi, dimanche |
| months | janvier, février, décembre |
| languages | le français, l'anglais, le vietnamien |
| nationality adjectives | une étudiante vietnamienne |
| the pronoun *je* in the middle of a sentence | Aujourd'hui, je travaille. |
| titles | monsieur Martin, madame Durand |

However, a noun that names a person from a country is capitalized: *un Français*, *une Vietnamienne*.

> **Tip:** quick memory aid: days, months, languages and nationality adjectives are all written in lowercase.
