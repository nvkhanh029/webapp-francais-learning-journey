# Frontend

The approved stack is React + Vite. Frontend Design is finalized: see
[`docs/frontend-design.md`](../docs/frontend-design.md).

This directory does not yet contain a React/Vite implementation, package
manifest, API client, UI mock, or dependency lockfile.

Backend contributors do not need Node.js, npm, or a running frontend for
backend-only work.

The project lead has opened Part 5: frontend implementation is authorized.
When implementing, follow `docs/frontend-design.md`, implement the shared
foundation first, and commit the actual package-lock.json generated by npm.
Do not reuse unverified v2 package pins.
